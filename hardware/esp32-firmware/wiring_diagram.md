## 详细引脚连接

### 按钮连接

每个按钮采用两线连接方式:

```
          按钮开关
         ┌─────────┐
         │  1   2  │
         │  ○   ○  │
         │         │
         │  3   4  │
         │  ○   ○  │
         └─────────┘
            │   │
            │   └──────────────► GND (ESP32)
            │
            └──────────────────► GPIO (ESP32)
```

### 具体接线表

| 按钮 | 按钮引脚 1 | 按钮引脚 2 | ESP32 引脚 |
|------|-----------|-----------|-----------|
| 沉淀键 | GPIO 14 | GND | 任意一端接 GPIO 14，另一端接 GND |
| 决策键 | GPIO 27 | GND | 任意一端接 GPIO 27，另一端接 GND |
| 重置键 | GPIO 26 | GND | 任意一端接 GPIO 26，另一端接 GND |

### LED 连接

ESP32 DevKit V1 通常内置蓝色 LED，连接到 GPIO 2。

如果需要外接 LED:

```
    GPIO 2 ──┬── [330Ω 电阻] ── [LED 正极] ── [LED 负极] ── GND
             │
             └── (可选: 板载 LED)
```

## 按钮类型说明

### 推荐按钮类型

**触感开关 (Tactile Switch) - 12mm**

```
    俯视图:
    ┌────────────┐
    │            │
    │   ○    ○   │  引脚 1,2 (连通)
    │            │
    │   ○    ◐   │  引脚 3,4 (连通)
    │            │
    └────────────┘
    
    底视图:
    ┌────────────┐
    │  1      2  │
    │            │
    │  3      4  │
    └────────────┘
    
    连接方式:
    - 引脚 1 和 2 内部连通
    - 引脚 3 和 4 内部连通
    - 按下时: 1-2 与 3-4 导通
    - 推荐连接: 1 接 GPIO，3 接 GND
```

### 按钮工作原理

```
    未按下状态:
    ────○  ○────    (断开)
    GPIO    GND
    
    按下状态:
    ────○──○────    (导通)
    GPIO    GND
    
    由于使用内部上拉电阻:
    - 未按下: GPIO 读取 HIGH (通过上拉电阻连接到 VCC)
    - 按下: GPIO 读取 LOW (直接连接到 GND)
```

## 可选扩展

### 添加外部 LED 指示灯

```
    GPIO 2 ──── [330Ω] ──── [LED+] ──── [LED-] ──── GND
                            │
                            └── 外部 LED (可选)
```

### 添加蜂鸣器反馈

```
    GPIO 25 ──── [1kΩ] ──── [NPN 基极]
                           │
                    [NPN 三极管]
                    集电极 ──── [蜂鸣器+] ──── [蜂鸣器-] ──── GND
                    发射极 ──── GND
```

### 添加状态 RGB LED (WS2812B)

```
    5V ──── [WS2812B VCC]
    GPIO 4 ──── [WS2812B DIN]
    GND ──── [WS2812B GND]
```

## 注意事项

1. **GPIO 选择**
   - 避免使用 GPIO 0, 2, 12, 15 (启动模式相关)
   - GPIO 34-39 仅输入，无内部上拉
   - 本设计使用 GPIO 14, 26, 27 安全可靠

2. **电源**
   - ESP32 工作电压: 3.0V - 3.6V
   - USB 供电: 5V (内部降压到 3.3V)
   - 建议使用 USB 供电

3. **按钮接线**
   - 确保按钮一端接 GPIO，另一端接 GND
   - 使用内部上拉电阻，无需外接电阻
   - 按钮按下时为 LOW，释放时为 HIGH

4. **防静电**
   - 操作前触摸接地物体
   - 避免直接触摸芯片引脚
