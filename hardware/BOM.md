## 详细规格说明

### 1. ESP32 开发板

**推荐型号:**
- ESP32 DevKit V1 (最常见，性价比高)
- ESP32-WROOM-32 开发板
- ESP32-S3-DevKitC-1 (更新版本)

**关键参数:**
- CPU: 双核 240MHz
- WiFi: 802.11 b/g/n (2.4GHz)
- 蓝牙: BLE 5.0
- GPIO: 30+ 可用引脚
- Flash: 4MB
- 工作电压: 3.0V - 3.6V
- USB: Micro USB 或 USB-C

**购买建议:**
- 选择带排针的版本，方便面包板使用
- 确认支持自动下载 (CH340/CP2102 芯片)
- 检查板载 LED 是否连接到 GPIO 2

### 2. 触感开关

**规格:**
- 尺寸: 12x12mm
- 类型: 四脚直插 (DIP)
- 动作力: 160-250gf
- 电气寿命: 100,000+ 次

**购买建议:**
- 选择带按键帽的套装 (不同颜色)
- 推荐颜色: 沉淀键(蓝)、决策键(绿)、重置键(红)

### 3. 面包板

**规格:**
- 点数: 830点 (标准尺寸)
- 尺寸: 约 165x55mm
- 电源轨: 2组

**购买建议:**
- 选择透明或彩色版本
- 确保接触良好
- 可选带底板和电源模块的套装

### 4. 跳线

**规格:**
- 公对公: 40根
- 公对母: 40根
- 母对母: 40根
- 长度: 20cm

**购买建议:**
- 购买套装更经济
- 选择多色套装，便于区分

### 5. USB 数据线

**规格:**
- 接口: Micro USB (ESP32) 或 USB-C (ESP32-S3)
- 长度: 1m
- 支持数据传输

**购买建议:**
- 确认支持数据传输 (部分线仅充电)
- 选择编织线更耐用
