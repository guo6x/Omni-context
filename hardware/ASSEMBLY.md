# 组装指南

本文档详细说明 Omni-Context ESP32 神经末梢的组装步骤。

## 准备工作

### 工具清单

| 工具 | 用途 | 必需 |
|------|------|------|
| 电脑 | 编程和调试 | ✅ |
| USB 数据线 | 连接 ESP32 | ✅ |
| 万用表 | 电路检测 (可选) | ⬜ |
| 剥线钳 | 处理跳线 (可选) | ⬜ |
| 镊子 | 处理小组件 (可选) | ⬜ |

- [ ] ESP32 开发板 x1

## 组装步骤

### 步骤 1: 准备面包板

1. 将面包板放置在平整的工作台上
2. 确认电源轨方向 (通常标记为 + 和 -)
3. 清理面包板孔位

```
    面包板布局
    ════════════════════════════════════════
    + ───────────────────────────────────── +
    - ───────────────────────────────────── -
    
    [主区域 - 放置组件]
    
    - ───────────────────────────────────── -
    + ───────────────────────────────────── +
    ════════════════════════════════════════
```

### 步骤 2: 安装 ESP32 开发板

1. 将 ESP32 开发板插入面包板中央
2. 确保 USB 接口朝外，方便连接
3. 检查所有引脚都正确插入孔位

```
    ESP32 安装位置
    
    ┌─────────────────────────────────────┐
    │                                     │
    │   [USB]                             │
    │    │                                │
    │   ┌┴┐                               │
    │   │ │  ESP32 DevKit V1              │
    │   │ │                               │
    │   │ │                               │
    │   └┬┘                               │
    │    │                                │
    └─────────────────────────────────────┘
```

**注意事项:**
- ESP32 开发板较宽，可能需要跨越面包板中央凹槽
- 确保引脚没有弯曲
- 检查开发板是否牢固

### 步骤 3: 连接 GND 总线

1. 使用跳线连接 ESP32 的 GND 引脚到面包板负电源轨 (-)
2. 使用跳线连接上下两部分的负电源轨

```
    GND 连接
    
    ESP32 ──── GND ──── 面包板 GND 轨 (-)
                          │
                          └── 连接上下 GND 轨
```

**GND 引脚位置:**
- ESP32 DevKit V1 通常有多个 GND 引脚
- 使用任意一个 GND 即可
- 建议使用靠近按钮位置的 GND

### 步骤 4: 安装按钮

#### 4.1 沉淀键 (GPIO 14)

1. 将触感开关插入面包板
2. 连接一端到 GPIO 14
3. 连接另一端到 GND

```
    沉淀键接线
    
    GPIO 14 ─────┬──────── [按钮引脚 1]
                 │
                 │      ┌─────────┐
                 └──────┤  按钮1  ├────── GND
                        └─────────┘
```

#### 4.2 决策键 (GPIO 27)

1. 将触感开关插入面包板
2. 连接一端到 GPIO 27
3. 连接另一端到 GND

```
    决策键接线
    
    GPIO 27 ─────┬──────── [按钮引脚 1]
                 │
                 │      ┌─────────┐
                 └──────┤  按钮2  ├────── GND
                        └─────────┘
```

#### 4.3 重置键 (GPIO 26)

1. 将触感开关插入面包板
2. 连接一端到 GPIO 26
3. 连接另一端到 GND

```
    重置键接线
    
    GPIO 26 ─────┬──────── [按钮引脚 1]
                 │
                 │      ┌─────────┐
                 └──────┤  按钮3  ├────── GND
                        └─────────┘
```

### 步骤 5: 检查接线

使用以下清单检查所有连接:

| 组件 | 引脚 1 | 引脚 2 | 状态 |
|------|--------|--------|------|
| 沉淀键 | GPIO 14 | GND | [ ] |
| 决策键 | GPIO 27 | GND | [ ] |
| 重置键 | GPIO 26 | GND | [ ] |
| GND 总线 | ESP32 GND | 面包板 GND 轨 | [ ] |

### 步骤 6: 完成组装

1. 检查所有连接是否牢固
2. 确保没有短路 (相邻引脚接触)
3. 整理跳线，保持整洁

## 最终检查

### 视觉检查

- [ ] ESP32 开发板牢固插入面包板
- [ ] 所有按钮位置正确
- [ ] 跳线连接正确
- [ ] 没有裸露的金属接触
- [ ] GND 总线连接完整

### 电气检查 (使用万用表)

**检查按钮:**

1. 设置万用表到电阻档
2. 未按下时，GPIO 和 GND 之间应为高阻 (内部上拉)
3. 按下时，GPIO 和 GND 之间应接近 0Ω

**检查 GND 连接:**

1. 设置万用表到通断档
2. 测量 ESP32 GND 引脚和面包板 GND 轨
3. 应该发出蜂鸣声 (导通)

## 烧录固件

### 连接电脑

1. 使用 USB 数据线连接 ESP32 到电脑
2. 等待驱动安装完成
3. 确认设备出现在设备管理器

**设备识别:**
- Windows: 设备管理器 → 端口 → USB-SERIAL CH340 (COMx)
- macOS: /dev/cu.usbserial-* 或 /dev/cu.wchusbserial*
- Linux: /dev/ttyUSB0 或 /dev/ttyACM0

### 烧录方法

参考 [esp32-firmware/README.md](esp32-firmware/README.md) 选择烧录方法:

#### PlatformIO (推荐)

```bash
cd hardware/esp32-firmware
pio run --target upload
pio device monitor
```

#### Arduino IDE

1. 打开 Arduino IDE
2. 选择开发板: ESP32 Dev Module
3. 选择端口
4. 打开 `src/main.ino`
5. 点击上传

## 首次配置

### 串口配置

连接串口监视器 (115200 波特率):

```
=====================================
   Omni-Context ESP32 神经末梢
   Firmware Version: 1.0.0
=====================================
首次运行，使用默认配置
配置已保存到EEPROM
当前配置:
  SSID: (未设置)
  密码: (未设置)
  UDP主机: 192.168.1.100
  UDP端口: 9090
按键初始化完成
未配置WiFi，请通过串口配置

进入配置模式
请通过串口命令配置WiFi:
  ssid <你的WiFi名称>
  pass <你的WiFi密码>
  host <桌面守护进程IP>
  save   (保存配置)
  connect (连接WiFi)
```

### 配置步骤

1. 设置 WiFi SSID:
   ```
   ssid YourWiFiName
   ```

2. 设置 WiFi 密码:
   ```
   pass YourWiFiPassword
   ```

3. 设置目标 IP:
   ```
   host 192.168.1.100
   ```

4. 保存配置:
   ```
   save
   ```

5. 连接 WiFi:
   ```
   connect
   ```

### 验证连接

成功连接后，串口输出:

```

IP地址: 192.168.1.xxx
MAC地址: xx:xx:xx:xx:xx:xx
UDP服务已启动，端口: 9090
OTA服务已启动
OTA主机名: omni-context-esp32
OTA密码: omni2024
系统初始化完成
```

## 可选扩展

### 添加外部 LED

1. 连接 LED 正极到 GPIO 2 (或任意 GPIO)
2. 连接 330Ω 电阻
3. 连接 LED 负极到 GND

```
GPIO 2 ─── [330Ω] ─── [LED+] ─── [LED-] ─── GND
```

### 添加蜂鸣器

1. 连接蜂鸣器正极到 5V
2. 连接蜂鸣器负极到 NPN 集电极
3. 连接 NPN 发射极到 GND
4. 连接 GPIO 到 NPN 基极 (通过 1kΩ 电阻)

```
GPIO 25 ─── [1kΩ] ─── 基极
                    NPN
5V ─── [蜂鸣器] ─── 集电极
GND ─────────────── 发射极
```

### 安装外壳

如果有 3D 打印外壳:

1. 将组装好的电路放入外壳
2. 固定按钮位置
3. 确保按钮可以正常按压
4. 使用 M3 螺丝固定外壳

## 故障排除

### ESP32 无法识别

1. 检查 USB 线是否支持数据传输
2. 安装 CH340 或 CP2102 驱动
3. 尝试其他 USB 端口

### 按钮无响应

1. 检查接线是否正确
2. 确认按钮连接到 GND
3. 检查串口输出

### WiFi 连接失败

1. 确认 WiFi 为 2.4GHz
2. 检查 SSID 和密码
3. 靠近路由器重试

### 编译错误

1. 确认已安装 ESP32 开发板支持
2. 检查 Arduino IDE 版本 (建议 2.0+)
3. 更新 ESP32 开发板包

## 维护建议

### 日常使用

- 避免在潮湿环境使用
- 不要拉扯跳线
- 定期检查连接

### 长期存放

- 断开 USB 电源
- 存放在干燥环境
- 避免阳光直射

### 固件更新

使用 OTA 无线更新:

1. 确保 ESP32 和电脑在同一 WiFi 网络
2. 配置 `platformio.ini` 中的 OTA 设置
3. 执行 `pio run --target upload`
