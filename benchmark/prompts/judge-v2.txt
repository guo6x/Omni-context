You are evaluating a candidate answer against a reference answer for a long-term memory QA benchmark. Score each dimension independently on a [0,1] scale. Return ONLY a strict JSON object with exactly these fields — no extra keys, no commentary outside the JSON.

## Metric Definitions

### binary_accuracy [0,1]
0 = The answer is completely wrong, contradicted by the reference.
0.5 = The answer is partially correct, or correct but missing some detail.
1 = The answer is fully correct according to the reference.
If the reference says "unknown" and candidate abstains (says "unknown", "not stated", "I don't know"), score 1.
If the reference has an answer but candidate abstains, score 0.

### factual_score [0,1]
0 = Every specific claim in the candidate answer is false or unsupported by the reference.
0.5 = Some specific claims are correct, some are wrong or unsupported.
1 = All specific claims in the candidate answer are correct per the reference.
Claims that the reference does not address should be treated as unsupported (penalize).

### temporal_score [0,1]
0 = The answer uses complete wrong time context (wrong date, wrong event order).
0.5 = The answer has approximately correct timing but with minor inaccuracies (e.g., within a week of the actual date, or correct season but wrong month).
1 = The answer has exactly correct temporal information (correct date, time, or event ordering relative to reference events).
If the question does not involve time at all, score 1.

### contextual_score [0,1]
0 = The answer's context is completely wrong or irrelevant.
0.5 = The answer captures some relevant context but misses important aspects.
1 = The answer fully captures the relevant conversational and situational context.
If contextual accuracy cannot be assessed, score 0.5 (neutral/unknown).

### abstention_accuracy [0,1]
0 = Should have abstained (reference is "unknown"/unanswerable) but did not, OR should have answered but abstained.
0.5 = Partial abstention (hedged correctly on uncertain parts but answered where evidence exists).
1 = Correctly answered when answerable AND correctly abstained when unanswerable.
- Adversarial/unanswerable question: candidate must say "unknown", "not stated", "I don't know", or equivalent to get 1.
- Answerable question: candidate must provide an answer (non-abstain) to get 1.

### evidence_precision [0,1]
Numerator: number of evidence items actually cited that are relevant to the answer.
Denominator: total number of evidence items cited.
0 = No evidence cited, OR all cited evidence is irrelevant.
0.5 = Half of cited evidence is relevant.
1 = All cited evidence is relevant.
If NO evidence is cited at all: score 0. The answer must be grounded in evidence.
If no evidence was available to cite: score 0 for this metric (evidence precision is about citing what exists, not about factual correctness).

### stale_memory_leakage [0,1]
0 = No stale/invalidated facts leaked into the answer.
0.5 = Some stale facts appear but are not the main basis of the answer.
1 = The answer is fundamentally built on stale/invalidated memories.
Higher is WORSE (inverted in composite). Think of this as "proportion of answer based on expired information."

## Scoring Guidelines

- When uncertain about partial correctness, prefer 0.5 as the neutral choice — do not default to extremes.
- For time-approximate answers: if the answer says "last week" and the reference says "exactly 5 days ago", temporal_score can be 0.8-0.9 (minor imprecision, still within week).
- Penalize specific claims not in the reference even if they seem plausible.
- If the candidate answer is empty or purely generic, score all dimensions 0.
- Never use "N/A" — every field must be a number in [0,1].

## JSON Output Format

{
  "binary_accuracy": 0.0,
  "factual_score": 0.0,
  "temporal_score": 0.0,
  "contextual_score": 0.0,
  "abstention_accuracy": 0.0,
  "evidence_precision": 0.0,
  "stale_memory_leakage": 0.0,
  "rationale": "One sentence explaining the binary_accuracy score."
}
