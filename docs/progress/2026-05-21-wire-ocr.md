# 2026-05-21 - Wire OCR

## 任务目标

接通 OCR 管道：让用户上传图片时自动 OCR 出文字、走和文本文件一样的知识图谱抽取流程。

## 改动文件清单

| 文件 | 改动 |
|------|------|
| `brain-server/src/ocr/pipeline.ts` | `_extractLocal()` 改为离线加载：`createWorker` 传入本地 `langPath`（`../../models/tessdata`）+ `gzip: true` + `cacheMethod: 'none'`；新增 `path`/`url` 导入 |
| `brain-server/src/api/handlers/ingest.ts` | 新增 `image/png`、`image/jpeg`、`image/webp` 及 `image/*` 兜底；图片分支用 `OCRPipeline` OCR 后走文本抽取流程；OCR 结果为空返回 422 |

## 关键说明

- `langPath` 用 `import.meta.url` 推算绝对路径：`join(dirname(fileURLToPath(...)), '../../models/tessdata')`
- tesseract.js v7 的类型声明对动态 import 偏窄，`createWorker` 调用用 `(Tesseract as any)` 绕过
- 图片上传仍走 buffer 校验（长度检查），OCR 时构造 `data:image/<type>;base64,...` data URL 传给 worker
- OCRPipeline 每次请求新建实例，用完 `dispose()` 释放 worker
- OCR 失败有 `_emptyResult` 兜底，`extractText` 返回空字符串 → ingest 返回 422
