# State and provenance

Structured `updated` and `superseded` transitions move the prior assertion to historical state. Structured `corrected` and `withdrawn` transitions invalidate the prior assertion and attach rejected-conflict evidence to the replacement. Reconciliation is restricted to the same subject and state key and never inferred from prose alone.

Source agent metadata comes only from the raw event envelope matched to the verbatim source span. The post-Targeted fix removed the unsafe fallback that rendered an assertion subject as its Speaker when no verified speaker existed.

The rerun preserved Cross-Agent isolation at 0 and detected no cross-scenario source-event leakage, but mandatory Memory Evolution and Conflict evidence did not survive final-context selection.
