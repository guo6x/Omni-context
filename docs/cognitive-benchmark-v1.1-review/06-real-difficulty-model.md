# Real Difficulty Model

Difficulty is validated from actual event count, reasoning hops, distractor ratio, conflict count, transition count, Agent count, and ambiguity factors. The generator rejects structural mismatches.

Formal Draft v2 has 75 Easy, 125 Medium, and 50 Hard scenarios. All 250 pass recomputation. Hard cases include 28–37 events, 2–4 conflicts, 2–5 transitions, 4–6 Agents, and an ambiguity factor; these ranges stay within the task's required Hard envelope.
