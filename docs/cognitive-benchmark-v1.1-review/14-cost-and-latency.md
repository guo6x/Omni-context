# Cost and Latency

Final Development recorded 145,292 DeepSeek Answer tokens, 59,248 DeepSeek Secondary Review tokens, and 60,488 Kimi Judge tokens. Observable DeepSeek Answer plus Secondary Review cost is estimated at USD 0.0296 using the pinned DeepSeek rate.

No verified Kimi K2.6 per-token price is pinned in benchmark configuration, so Kimi dollar cost is `N/A` rather than inferred. Frozen Brain Server extraction does not expose complete provider token usage, so extraction cost is also excluded.

The partial Formal 250 projection is 355,977 DeepSeek Answer input tokens, 115,750 Answer output tokens, 103,539 Kimi prompt tokens, and 13,535 Kimi completion tokens. Projected DeepSeek Answer cost is USD 0.0672; Kimi and extraction cost remain excluded. Linear runtime estimate is 8.24 hours.

Full Omni latency P50/P95 is 112.536/200.541 seconds. Kimi physical-attempt latency P50/P95 is 3.948/5.182 seconds.
