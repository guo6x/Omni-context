# Scenario Family Design

Formal Draft v2 contains 59 scenario families across seven categories:

| Category | Families |
| --- | ---: |
| Cognitive Continuity | 7 |
| Memory Evolution | 8 |
| Conflict Resolution | 7 |
| Cross-Agent Transfer | 8 |
| Human-like Forgetting | 9 |
| Proactive Insight | 10 |
| Decision Quality | 10 |

Each category has at least five families, and no family exceeds 25% of its category. Development uses five distinct families per category and includes Easy, Medium, and Hard.
