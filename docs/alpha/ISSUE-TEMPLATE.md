## 立即停止并升级的情况

如果暂停捕获后仍截屏/读剪贴板、敏感应用出现在捕获结果、未知前台窗口仍被读取、
隐私策略同步失败却显示已暂停，或数据库出现丢失/覆盖迹象：

1. 立即停止捕获并退出 Omni-Context；
2. 不要继续重试、上传或删除数据；
3. 记录版本、安装包 SHA-256、时间和最小重现步骤；
4. 若已有与邀请方双方确认的私人渠道，自行选择通过该渠道报告并标记 `P0 privacy/data`；若没有，先停止试用、保留本地问题记录，不要上传截图、日志或数据库；
5. 只在用户明确同意后提供脱敏截图或日志。
