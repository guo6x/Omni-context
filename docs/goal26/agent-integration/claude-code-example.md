# Claude Code example

Use the same MCP profile and environment-variable credential as the Codex
example. The profile is portable because it exposes only the four
`agent_*` tools. Claude Code (or another client) may ask and observe, but it
cannot approve, execute, invoke read-back, or access native/store internals.

This file is a static configuration example; it is not a claim that a Claude
runtime E2E was executed.
